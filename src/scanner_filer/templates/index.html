Setup

Use these sections to configure: 1) NAS destination storage, 2) Pi scanner upload shares, 3) user accounts, and 4) AI filing behavior.

NAS Samba Setup

This connects the Pi to your NAS. The NAS Share Name is the remote shared folder on the NAS (often "Public"). The Subdirectory is your filing folder inside that share (for example "Home Filing").

Scanner Inbox Samba Setup

This creates a Samba upload share on the Pi itself for scanners. It is separate from NAS login. Use this if you want one general scanner share.

User Inboxes

Create one scanner inbox per person. Each person can have their own NAS login and own destination filing root.

Field guide: NAS Share Name is the remote NAS share (often "Public"). Subdirectory is the folder inside that share (for example "Home Filing"). Apply User Inboxes below creates Samba shares on the Pi for scanner uploads.

Important: the Samba username for each Pi scanner share is the inbox name (for example Rob -> scanner_Rob with username Rob). The Samba password here is for those Pi shares and is separate from web login account passwords.
